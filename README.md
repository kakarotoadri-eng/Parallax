## 🔍 How Parallax Improves Reliability

The software monitors requests sent to your agent. It checks the output for common mistakes. If the agent makes a mistake, the software triggers a correction loop. This ensures that the agent attempts to fix the error before giving you a final result. 

Parallax also manages the context window of your agent. It keeps track of important information to prevent the agent from forgetting current tasks. This approach reduces confusion and keeps the agent focused on the goal.

## ⚙️ Configuring Settings

Open the Settings tab to change how your agent behaves. You can adjust the temperature setting to control creativity. Lower numbers lead to predictable, stable answers. Higher numbers allow for more varied responses. 

You can also set a retry limit. This tells the software how many times to fix a mistake before stopping. We recommend a limit of three attempts for most tasks.
